# 2026 World Cup Brand Tracker — Wave 1

An interactive data explorer of the **2026 World Cup Brand Tracker (Wave 1)** for
**Voice of the Trade**, a Potentia Sports product.

The page lets you slice the survey yourself — toggle **Public vs Trade**, break the
whole survey by demographics, sort, hover for exact figures, and compare the two
audiences side by side on every question.

## The study

Two UK panels were fielded simultaneously, **5–10 June 2026**:

- **Opinion Pulse** — UK general public, **n = 244**
- **Voice of the Trade** — verified UK tradespeople, **n = 116**

Every figure on the page is computed directly from the raw response file (one row per
respondent), filtered by panel and demographic — not from pre-summarised tables. Results
are unweighted percentages of the responding base for each question; multi-code questions
sum to more than 100%, and sub-bases under ~30 are flagged as indicative.

## Viewing the page

Open **`05 Web Report/worldcup_tracker_vott_wave1.html`** in any modern browser. It is a
single self-contained file — the logos are embedded and all data is inline, so it works
offline. The Rework brand typeface is referenced but falls back to a web-safe grotesque,
since the Rework files are trial-licensed and are not shipped in this repository.
